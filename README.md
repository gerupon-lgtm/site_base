# SITE BASE by SIKUMI LAB

小規模店舗・教室・サービス業向けの、公開サイトと利用者向け設定画面の見本です。シクミラボと懇意にしている友人に限定した取り組みで、一般向けの無料サービスとして募集するものではありません。

[公開サイト](https://site-base.sikumilab.com/)／[設定画面](https://site-base.sikumilab.com/admin.html)／[提供条件](https://site-base.sikumilab.com/terms.html)

## 見本で試せること

画面上部でお店・教室・サービス業を切り替え、名称・価格・写真・お知らせの変更、追加、非表示・再表示、表示順を試せます。掲載内容はカードを長押しして移動でき、↑↓ボタンも使えます。移動後に順番を確認し、OKで反映します。取消なら元の順番が残ります。写真は表示枠に合わせて中央で切り取ります。変更内容を確認してから確定します。

NEWの有無・自動／手動の表示、公開予約・自動終了も試せます。お知らせは保存最大20件・公開表示最大10件。問い合わせは架空の受付履歴と対応状況を確認できます。

**変更は操作したブラウザ内だけに保存されます。メール認証・メール送信・別端末への共有は行いません。実際の個人情報は入力しないでください。** ブラウザの保存データを消すと変更内容も消えます。

掲載内容・お知らせの双方で、チェックボックスから複数のバッジを選択。おすすめ・期間限定・キャンペーン・数量限定・売り切れ・受付停止・終了に加え、全角6文字までの自由入力を各項目に1つ付けられます。NEWの有無・自動／手動の設定も維持します。

[概要](docs/site-base-overview.md)／[提供条件の確認資料](docs/site-base-conditions.md)

公開後の内容更新・アカウント管理・契約更新は利用する方へ引き継ぎます。サイトについての相談は、シクミラボとの普段の連絡でお願いします。第三者への再配布・販売は事前にご相談ください。相談があれば、提供済みのサイトから派生する形で渡せる範囲を確認します。

## 作業内容と公開内容を分ける更新の流れ

掲載メニュー・レッスン・サービスの追加・編集・写真の差し替え／取り外し・非表示／再表示・削除・並び替えを、まとめて編集できます。並び替えなどの操作ごとに確認ダイアログを出しません。各編集画面で「作業一覧へ追加」し、最後に「変更内容を確認」→「確定・まとめて反映」で公開用の内容へ反映します。お知らせ、ページ内の写真、基本情報、NEWの共通日数も同じ最後の確定へ揃えます。

作業中の内容は公開用とは別にブラウザ内へ保存し、ページを開き直しても続けられます。最後の確認を閉じても作業は残り、「未反映の変更を取り消す」で公開中の内容へ戻せます。公開画面は確定まで変わらず、写真を外した場合も確定後に画像枠を省きます。トップ・ご案内の写真も取り外し／再追加ができます。

写真を選んだだけ・入力中のまま編集ダイアログを閉じた場合は、その入力を作業一覧へ追加しません。追加済みの作業内容と、入力途中の内容を区別します。メール通知や本番公開はまだ接続せず、現在はブラウザ内の操作見本です。

問い合わせの対応状況と内部メモは公開情報とは別に保存します。受付が増えても公開用の変更と混ぜず、最後の確定時にも最新の受付履歴を保持します。


確認画面はアイテムごとに名称・追加／変更／削除をまとめ、枠内の表で「項目・変更前・変更後」を比較します。写真も同じ枠で確認できます。追加や削除で番号がずれただけのアイテムは、並び替えとして列挙しません。削除も最終確定までは作業中で、未反映の変更を取り消すと元に戻ります。確認から編集へ戻るだけなら削除予定を含む作業を保持します。確定後の一覧は「未反映の変更はありません」と表示し、表示確認時刻は予約・NEW等の判定時刻の案内です。


### 編集を閉じるとき

未保存の入力がある場合は、反映する・反映せずに終了・編集を続けるを選べます。「反映する」は変更内容の確認へ進み、最後の確定で反映します。作業一覧へ追加した内容は、反映せずに終了しても次回再開できます。入力途中の内容を残すには、先に作業一覧へ追加してください。ブラウザのタブを閉じる・再読み込みの場合は、ブラウザ標準の確認が出ます。

最後の確認は、アイテムごとに「変更前 → 変更後」を並べたコンパクトな表示です。追加は新しい内容、削除は対象名と削除を表示し、変更した写真も同じ枠で確認できます。


編集と確認の画面は、内容だけをスクロールして確認できます。閉じるボタンと、作業一覧への追加・編集へ戻る・確定などの主な操作は画面内に残ります。PC・スマホとも同じ配置です。
