# SITE BASE by SIKUMI LAB — 提供条件の確認資料

2026年10月4日更新／提供条件 第3版

身近な人の事業を、自分で更新できるサイトで支える。そのための、友人に限定した取り組みです。この条件は、シクミラボからサイトの提供を受ける方へ向けたものです。一般向けの無料サービスとして募集するものではありません。

## 1. 親しい友人に限定した提供

シクミラボと懇意にしている友人だけを対象に、無償で提供します。基本的に、紹介などによる依頼は受け付けません。

## 2. 初回の制作と公開後の管理

最初の制作・設定・初回公開はシクミラボが行います。公開後の写真・価格・お知らせの更新、問い合わせへの返信、契約更新、アカウント管理は、利用する方が行います。

独自ドメインや外部サービスに発生する費用は、利用する方の負担です。必要な契約や無料で利用できる範囲は、提供前に確認します。

## 3. 店舗・サービスの運営について

シクミラボはサイトの仕組みを提供し、営業方針、商品・サービスの内容、価格設定、顧客対応には関与しません。これらの判断と運営は、利用する方が行います。

予約・注文への対応、問い合わせへの返信、お客様とのやり取りも、利用する方が行います。

## 4. 掲載する情報・写真・文章

価格・営業時間などの掲載情報は、利用する方が内容をご確認ください。ご自身で用意する写真・文章には、掲載してよいものを使用してください。

## 5. サイトについての相談と追加対応

クレームは受け付けません。サイトの動作不良や表示内容についての相談は、友人同士の常識的な範囲で受け付けます。ご希望どおりの修正や即時対応を約束するものではありません。

提供後の機能追加やデザイン変更は、ご相談の内容に応じて、対応できる範囲をその都度判断します。

## 6. シクミラボの制作事例として紹介

シクミラボの紹介ページに、制作事例としてサービス名（店名）と公開サイトのURLを掲載する場合があります。この範囲の掲載について、提供時にまとめて了承していただくことを、提供の条件とします。

紹介用の画像には、共通のサンプルページを使用します。

## 7. 実装した機能の共通利用

相談して実装した機能は、他の利用者にも使えるようにします。掲載情報・写真・問い合わせ内容など、利用する方に固有の情報を共通利用するものではありません。

## 8. 第三者への再配布・販売

ご自身のサイトとして利用・更新できます。提供したサイトやコードを第三者へ再配布・販売する場合は、事前にシクミラボへご相談ください。

事前に相談いただいた再配布は、内容に応じてお渡しできるものを確認します。提供済みのサイトやコードから派生する形とし、シクミラボ内部の共通保管庫・設計資料・ひな形・制作スキルはお渡ししません。

提供前に、掲載する内容と必要な機能、公開後の更新方法を一緒に確認します。
