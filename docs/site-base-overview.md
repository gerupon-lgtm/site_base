# SITE BASE by SIKUMI LAB

## 店舗・教室・サービス業のための、自分で更新できるWebサイト

2026年10月9日更新／概要資料 第21版

価格、写真、お知らせなど、日々の営業に合わせて変わる情報があります。それを使う人が自分で更新できるよう、**公開用のWebサイトと、編集用の設定画面をセットで用意する仕組み**を考えています。

最初のデザイン・設定・公開はシクミラボが行い、公開後の内容更新やアカウント管理は、利用する方に引き継ぐ方針です。

**現在は、参考サンプルと仕様の検討を進めている段階です。以下は提供予定の内容で、すべての機能が完成しているわけではありません。** 「追加検討」は候補、「要相談」はまだ決めていない内容です。

写真や掲載内容を保存し、メールで通知する仕組みも、内部テストで確認を進めています。公開中の見本はブラウザ内だけで動きます。提供時には、その方の保存先とログイン・通知を個別に整え、実際の操作を確認してから引き継ぎます。

## 1. どんな方に向いているか

小規模なお店、教室、個人・小規模のサービス業を対象にしています。

- 飲食店：メニューや価格、期間限定の商品、お店からのお知らせを更新したい。
- 教室：レッスン案内や料金、募集のお知らせを更新したい。
- サービス業：サービス内容や料金、キャンペーンを分かりやすく紹介したい。

**提供先は、シクミラボと懇意にしている友人に限定します。基本的に、紹介などによる依頼は受け付けません。** 必要な内容を相談し、無償で作成する取り組みです。一般向けに無料で提供するサービスではありません。

**SITE BASE by SIKUMI LABは仕組みの名前**で、公開サイトにはそれぞれのお店・教室・事業の名前を使います。

## 2. 更新するときの流れ

編集用の設定画面に入り、変更内容を確認してから公開する流れです。PC・スマートフォンの両方で操作できるようにします。

1. 登録したメールアドレスに届く認証コードで、設定画面に入る。
2. 価格、写真、お知らせなどを変更する。
3. 変更した内容を確認する。
4. 今すぐ公開するか、公開日時を指定して確定する。

例えば、メニューの価格変更なら「価格を直す → 内容を確認する → 公開する」という操作を想定しています。写真の差し替えやお知らせの追加も、設定画面から行えるようにします。

## 3. 基本として用意する予定の機能

| 項目 | できるようにすること |
| --- | --- |
| 公開サイト | PC・スマートフォンで読みやすく表示。ページ内の案内メニューはスクロール中も操作できるようにする |
| メニュー・商品・サービス・レッスン | 名称・価格の変更、追加、非表示・再表示、長押しドラッグや↑↓による表示順の変更 |
| 写真 | ページ内の画像ごとに差し替え。初期制作で画像が増えた場合も、それぞれに編集欄を用意。縦横比を保ち、表示枠に合わせて中央を基準に切り取って表示 |
| 営業日・時間・受付時間 | 文章または表で表示。形式は初期設定で固定し、公開後は時間・休業情報・補足を編集する。表の機能はこれから実装 |
| お知らせ | 追加・編集・非表示・再表示。タイトル横に選択したバッジとNEWを表示し、押すと写真や本文などの詳細を表示。スマホでは画面下部に開き、外側を触るか閉じるボタンで閉じる。複数ピックアップを先頭に固定し、長押し・↑↓で表示順を変更。「日付順に戻す」も最後の確認・確定で反映 |
| 公開する期間 | お知らせ・キャンペーン・メニューを今すぐ公開、または予約公開。終了日時を設定することも、設定しないことも可能 |
| 共通バッジ | メニュー・商品・サービス・レッスンとお知らせに、複数のバッジをチェックで付ける。自由入力は各項目に1つ、全角6文字まで |
| NEW表示 | 付ける・付けないを選択。付ける場合は、指定日数後に自動で消す方式と、手動で外すまで残す方式を選択 |
| 最終更新日 | 公開サイトに更新日を表示し、情報の新しさを確認できるようにする |
| お問い合わせ | 必要な場合にフォームを設置。受付履歴を設定画面に残し、普段のメールへ通知 |

### 期間を決めて掲載する

「来月から新メニューを載せたい」「キャンペーン期間だけ案内を出したい」といったときに使えます。

| 開始 | 終了 | 例 |
| --- | --- | --- |
| 今すぐ | 終了なし | 通常のメニュー・サービス案内 |
| 今すぐ | 日時を指定 | 今日から始まる期間限定の案内 |
| 日時を指定 | 終了なし | 来月からの新メニュー・レッスン案内 |
| 日時を指定 | 日時を指定 | 指定期間のキャンペーン |

ここでいう予約は「Webサイトへの掲載を予約する」ことです。来店予約やレッスンの予約受付とは別です。

### 目印になるバッジを付ける

おすすめ・期間限定・キャンペーン・数量限定・売り切れ・受付停止・終了から、必要なものを複数選べます。自由に名前を付けるバッジも、各項目に1つ、全角6文字まで設定できます。使わない場合はチェックを外します。

NEW以外は、チェックを外すまで残ります。「終了」も表示する言葉で、掲載の終了日時とは別です。売り切れや受付停止の表示を選んでも、在庫数や予約受付が自動で変わる仕組みではありません。

### NEWの表示方法

まず、案内ごとに「NEWを付ける・付けない」を選べます。付ける場合の消し方を、自動または手動から選びます。

自動で消す場合の日数は、サイト全体で1つ設定します。NEWは初めて公開したとき、または「NEWを付け直す」を選んで公開したときに開始します。通常の価格修正や並べ替えでは、表示期間を延ばさない仕様です。

手動方式では、自分で外すまで残します。NEWの初期表示日数や、日数を途中で変更したときの扱いは、提供前に整理します。

## 4. お問い合わせを受ける場合

メール通知に加えて設定画面にも履歴が残るので、メールを見落としても受付内容を確認できる形にします。

**訪問者が送信 → 受付履歴を保存 → 普段のメールへ通知 → メールで返信 → 設定画面で対応状況を更新**

- 返信は普段使っているメールから行う。
- 設定画面では「未対応／対応中／対応済み」を手動で管理する。
- 受付内容を残したまま、内部メモを追加・更新する。
- 受付履歴と内部メモは、一般の訪問者には公開しない。

公開後は、利用する方が日常の問い合わせを確認し、返信と対応状況の更新を行います。

**要相談：** フォームの入力項目、通知先、受付確認メールの有無、履歴の保存件数・期間。フォームを設けるかどうかも、普段の電話・メール・SNSでの受付方法に合わせて相談できます。

## 5. 自分の事業に合わせるところ

最初に、公開名、写真、紹介文、メニュー・サービス内容、連絡先などを合わせます。「お品書き」「サービス」「レッスン」など、見出しも事業に合わせる考え方です。デザインと必要な情報を相談し、初期設定を行います。

### 見た目は3案を画像で比較して決める

色・文字・余白・写真の見せ方などの雰囲気が異なる3案を画像で比較し、選んだ案をもとに初期デザインを作ることを基本にします。必要な調整も相談できます。比較する案は提供先に合わせて用意し、選択内容はヒアリングシートに残します。

これは制作前の選択です。公開後に設定画面からデザインを切り替える機能とは別です。

### 営業情報は文章または表でまとめる

時間がほぼ共通なら文章、曜日や時間帯で違うなら表が向いています。導入前に相談して決め、**表示形式はシクミラボが初期設定のコードで固定します。利用者向けの設定画面には、文章／表の切り替えは設けません。**

文章表示では時間・定休日・補足を、表表示では時間帯の時間・曜日ごとの営業／休業・補足を編集できるようにします。表の見出し・行数などの構成は初期設定で決め、形式や構成を変える場合は改めて相談します。スマホでも読みやすく表示する形を用意します。

現在の見本は文章の編集のみです。表の表示・編集は今後の実装内容です。

### ページ内の写真を差し替える

ページ内の写真は、初期制作で決めた位置・表示枠ごとに設定画面から差し替えます。「ページの写真」で画像の名前と見本を確認して選び、変更前後を確認して反映します。画像枠の追加や配置の変更は初期制作・改修時に行い、追加した枠にも差し替え欄を用意します。商品・サービス・お知らせの写真は、各項目の編集画面から変更できます。

### 追加で検討しているもの

次の内容は、設定画面に追加する候補として検討しています。必要なものを確認してから、提供する範囲を決めます。

| 追加検討しているもの | 利用例 |
| --- | --- |
| 基本情報の編集範囲の拡張 | 電話・地図・SNSリンクなどの変更。公開名・紹介文・住所・営業時間・休業日は、現在の見本で編集できる |
| 料金の表記方法 | 月額、〇円から、要相談、価格を表示しない |
| 営業・受付の例外 | 特定日の臨時休業や特別営業を自動で反映。通常の時間表とは別の追加検討 |
| 目立たせたい案内 | 「本日臨時休業」などをページ上部に表示 |
| 写真の調整範囲の拡張 | 切り取り位置の調整。容量を小さくする処理と中央トリミングは、現在の見本で試せる |
| よくある質問 | 質問と回答の追加・編集・並べ替え |
| 公開内容の確認・復元 | 公開前の見え方の確認、以前の内容へ戻す |

SNSとの連携も、必要な使い方が見えたところで検討します。現在決まっている掲載機能や、SNSへのリンク設置と、SNSへの同時投稿などの連携は分けて考えます。

## 6. 制作・公開・管理の担当

共通の仕組みを使いながら、アカウントと内容は利用する方ごとに持つ形です。これにより、公開後は自分のサイトとして管理できます。

| 担当 | 内容 |
| --- | --- |
| シクミラボ | 最初のデザイン・内容の調整、必要なサービスの初期設定、初回公開、操作方法と管理方法の説明 |
| 利用する方 | 写真・価格・お知らせの更新、問い合わせへの返信、アカウント管理、契約更新、必要な外部費用の支払い |

引き継ぎ時には、更新操作とあわせて、アカウント、契約、更新時期などを確認できるように整理します。機能追加やデザイン変更は相談ごとに対応できる範囲を判断します。改修版の具体的な取り込み方は、引き渡し前に整理します。

ドメインメール（独自ドメインのメールアドレス）の作成・設定や、メールソフト・スマートフォンのメール設定は、サイト提供の範囲に含まれません。

**シクミラボが提供するのはサイトの仕組みです。** 営業方針、商品・サービスの内容、価格設定、顧客対応には関与しません。予約・注文への対応や問い合わせへの返信など、事業の日々の判断と運営は利用する方が行います。

## 8. 導入までの進め方

2. 写真・文章・価格・連絡先を用意する。雰囲気の異なる3案を画像で比較して選び、必要な調整と営業時間の表示形式を相談する。

## 9. 確認してほしいこと

初期制作の前に、掲載したい内容と自分で更新したい項目を相談して整理します。未定の部分は、相談しながら決められます。

次の3点について、分かる範囲で教えてください。

1. **自分で更新したい情報は何ですか？** 価格、写真、お知らせなど、よく変わるものを教えてください。
   → 設定画面に必要な項目と、初期設定する内容に反映します。
2. **事前に用意して、決まった期間だけ掲載したい案内はありますか？** 季節商品、募集、キャンペーンなどの例があれば教えてください。
   → 公開予約や掲載期間を、どのように使うと便利か具体化できます。
3. **サイトからのお問い合わせフォームは必要ですか？** 電話・メール・SNSで十分か、フォームでも受けたいかを教えてください。
   → フォームを設けるかと、通知・対応管理の設定を決めます。

事前に相談いただいた再配布は、内容に応じてお渡しできるものを確認します。提供済みのサイトやコードから派生する形とし、シクミラボ内部の共通保管庫・設計資料・ひな形・制作スキルはお渡ししません。

利用する方にはサイトのコードと日常の利用・管理に必要な説明をお渡しします。環境構築や開発の手順、内部の設計資料は含めません。

## 10. 現在の表示・操作サンプル

掲載内容は、カードを長押しして移動できます。PC・スマホとも同じ操作で、↑↓ボタンも使えます。移動先には「ここに移動」が表示され、離すと変更前後の順番を確認できます。OKで反映し、取消なら元の順番が残ります。指をすぐ動かした場合は、いつもどおりスクロールできます。

SITE BASE用に、公開サイト・利用者向け設定画面・提供条件ページの見本を用意しています。画面上部で「小さなお店・教室・サービス業」を切り替えて確認できます。

お知らせはタイトルとNEWを一覧に表示し、押すと写真や本文などの詳細を開きます。PCは掲載メニューと同じ画面中央、スマホは画面下部に表示し、外側の操作または閉じるボタンで閉じます。見本記事は公開中3件と予約公開1件。保存最大20件・公開表示最大10件です。

公開サイト上部のSITE BASEの帯は「×」で隠し、左下のボタンで戻せます。お店の名前と案内メニューは残ります。設定画面のヘッダは2行のブランド表記で、下段の文字間を均等に調整して左右端を揃えます。設定項目を切り替えると画面位置を先頭に揃えます。コピーライトは公開・設定・提供条件の各ページの最下部に控えめに表示します。

掲載内容・お知らせの双方で、チェックボックスから複数のバッジを選択。おすすめ・期間限定・キャンペーン・数量限定・売り切れ・受付停止・終了に加え、全角6文字までの自由入力を各項目に1つ付けられます。NEWの有無・自動／手動の設定も維持します。公開予約・自動終了、問い合わせの受付と対応状況も、ブラウザ内だけで試せます。設定画面では「表示確認時刻」を進めて、掲載期間の変化を確認できます。最終更新日は公開ページの「ご案内」に表示します。

「ページの写真」ではトップ画像とご案内画像をそれぞれ変更でき、変更前後のプレビュー・取消・編集へ戻る操作を試せます。写真の説明も編集できます。写真は表示枠を埋めるように中央で切り取り、別の枠の写真はそのまま残します。

[公開サイトの見本](https://site-base.sikumilab.com/)／[設定画面の見本](https://site-base.sikumilab.com/admin.html)／[提供条件の見本](https://site-base.sikumilab.com/terms.html)

**この見本はメール認証せずに開けます。メール送信は行いません。フォームには架空の内容で入力してください。** 本番の認証・共有保存・通知は、別途接続して確認する内容です。

### 使用している技術

現在のSITE BASEサンプルはHTML・CSS・JavaScriptで画面を作り、ブラウザ内の保存機能で編集体験を試せる構成です。写真の容量調整にはCanvas・WebP、共通イラストにはSVGを使用します。コードはGitHubで管理し、Cloudflare Pagesへ自動公開しています。

本番のメール認証、共有保存、通知は、CloudflareとResendを使う方向で検討しています。認証・共有保存・メール通知は、提供前に実際の動作を確認して引き継ぎます。

## 作業内容と公開内容を分ける更新の流れ

掲載メニュー・レッスン・サービスの追加・編集・写真の差し替え／取り外し・非表示／再表示・削除・並び替えを、まとめて編集できます。並び替えなどの操作ごとに確認ダイアログを出しません。各編集画面で「作業一覧へ追加」し、最後に「変更内容を確認」→「確定・まとめて反映」で公開用の内容へ反映します。お知らせ、ページ内の写真、基本情報、NEWの共通日数も同じ最後の確定へ揃えます。

作業中の内容は公開用とは別にブラウザ内へ保存し、ページを開き直しても続けられます。最後の確認を閉じても作業は残り、「未反映の変更を取り消す」で公開中の内容へ戻せます。公開画面は確定まで変わらず、写真を外した場合も確定後に画像枠を省きます。トップ・ご案内の写真も取り外し／再追加ができます。

写真を選んだだけ・入力中のまま編集ダイアログを閉じた場合は、その入力を作業一覧へ追加しません。追加済みの作業内容と、入力途中の内容を区別します。メール通知や本番公開はまだ接続せず、現在はブラウザ内の操作見本です。

問い合わせの対応状況と内部メモは公開情報とは別に保存します。受付が増えても公開用の変更と混ぜず、最後の確定時にも最新の受付履歴を保持します。


## 変更確認の見やすさ（20261004-20）

確認画面はアイテムごとに名称・追加／変更／削除をまとめ、枠内の表で「項目・変更前・変更後」を比較します。写真も同じ枠で確認できます。追加や削除で番号がずれただけのアイテムは、並び替えとして列挙しません。削除も最終確定までは作業中で、未反映の変更を取り消すと元に戻ります。確認から編集へ戻るだけなら削除予定を含む作業を保持します。確定後の一覧は「未反映の変更はありません」と表示し、表示確認時刻は予約・NEW等の判定時刻の案内です。


### 編集を閉じるとき

編集画面を閉じるときは「変更内容を確認／入力を破棄して閉じる／編集を続ける」を選べます。「変更内容を確認」は最後の確認へ進み、その時点では公開側を変更しません。「入力を破棄して閉じる」は、その画面で作業一覧へ追加していない入力だけを取り消します。最後の確認の「作業を残して閉じる」は、作業一覧を保持するので次回再開できます。作業全体を取り消す場合は「未反映の変更を取り消す」→「変更を取り消す」を選びます。ブラウザのタブを閉じる・再読み込みの場合は、ブラウザ標準の確認が出ます。

最後の確認は、アイテムごとに「変更前 → 変更後」を並べたコンパクトな表示です。追加は新しい内容、削除は対象名と削除を表示し、変更した写真も同じ枠で確認できます。


編集と確認の画面は、内容だけをスクロールして確認できます。閉じるボタンと、作業一覧への追加・編集へ戻る・確定などの主な操作は画面内に残ります。PC・スマホとも同じ配置です。


## 掲載内容の見分けやすさ

公開側の掲載内容は、商品・レッスン・サービスごとに白いカードへまとめます。一覧には小さな写真・名称・バッジ・価格を表示し、カードを押すと詳しい説明と大きな写真が開きます。写真は左側、写真なしの名称は左端から表示する配置です。写真なしでは画像枠と専用余白を省き、代替画像や「NO IMAGE」は出しません。スマホは内容に合わせた高さで表示し、写真付きへ高さを合わせるための空白を設けません。

詳しい説明は、PCでは画面中央、スマホでは画面下部に開きます。外側を押す・閉じるボタン・Escapeで閉じます。写真なしは説明とバッジ・価格だけを表示。大きな写真は全体を確認できる形とし、一覧の小さな写真は中央でトリミングします。長文は詳細の中だけをスクロールし、閉じるボタンは常に操作できます。

### お知らせの固定表示と並び順

ピックアップは複数指定でき、公開中の記事の先頭へまとめて表示します。ピックアップ内と通常の記事内は、投稿日に関係なく長押しドラッグ・↑↓で並べ替えます。ピックアップと通常の記事の境界は越えません。

「日付順に戻す」は、それぞれの区分を投稿日が新しい順に並べ直す操作です。同じ日付なら直前の順を維持します。以後の日付編集で再び自動整列する設定ではありません。並べ替え・日付順への戻し・ピックアップ変更は作業内容へ保存し、最後の「変更内容を確認」→「確定・まとめて反映」まで公開側は変わりません。未反映の変更の取り消しも可能です。

非表示・下書き・公開待ち・終了の記事は公開しません。ピックアップも表示最大10件に含み、保存は非表示等を含めて最大20件です。並べ替えでは投稿日、NEW開始日、公開期間、写真・本文は変えません。
